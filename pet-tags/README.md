# Конструктор адресников для питомцев (3D)

Клиент сам собирает адресник и сразу видит его в 3D: форма, размер, материал и цвет, надпись спереди
(имя, вторая строка, шрифт, значок), обратная сторона (телефон), шнурок / цепочка, бусины
(в т.ч. буквы), стразы, подарочная коробочка, срочность и пожелания. Каждая деталь появляется
с анимацией, модель можно крутить и переворачивать, кнопка «Сборка» показывает изделие поэтапно.
Цена пересчитывается на лету с подробным составом.

## Запуск локально
```bash
cd pet-tags && python3 -m http.server 8000   # открыть http://localhost:8000
```
Сборка не нужна: чистые HTML/CSS/JS, Three.js подключается с CDN.

## Что менять под себя — `js/config.js`
- `brand`, `tagline` — название мастерской;
- `contacts.whatsapp` (цифры, без «+») и `contacts.telegram` (ник без @) — **обязательно замените заглушки**;
- все цены: формы, размеры, материалы, цена за символ спереди/сзади, значки, шнурки, каждая бусина, стразы, допы;
- палитры цветов и лимиты длины надписей.

## Как приходит заказ
1. **Без сервера (по умолчанию).** Клиент заполняет имя и телефон → получает готовый текст заказа
   (состав, цвета, бусины по порядку, расчёт, пожелания) и отправляет его в WhatsApp (текст подставляется
   автоматически) или Telegram (текст копируется). Фото макета скачивается кнопкой.
2. **Автоматически в Telegram (рекомендуется).** Функция `api/order.js` пересылает мастеру фото макета и текст заказа.
   - создать бота у @BotFather → `TELEGRAM_BOT_TOKEN`; узнать свой chat id (например, через @userinfobot) → `TELEGRAM_CHAT_ID`;
   - задеплоить папку `pet-tags` на Vercel (Root Directory = `pet-tags`), добавить эти две переменные окружения;
   - в `config.js` указать `orderEndpoint: '/api/order'`.
   Если отправка не удалась, клиенту автоматически показываются ручные способы.

## Структура
- `index.html`, `css/style.css` — страница (адаптив под телефон, тёмная тема);
- `js/app.js` — панель шагов, состояние (сохраняется в браузере), оформление заказа;
- `js/scene.js` — 3D-сцена: адресник, гравировка, стразы, колечко, шнурок/цепочка, бусины, анимации;
- `js/shapes.js` — контуры форм; `js/pricing.js` — расчёт цены и текст заказа;
- `api/order.js` — приём заказа и отправка в Telegram.
