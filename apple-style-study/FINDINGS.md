# Что показал разбор apple.com (Playwright, 07.11.2026)

Собраны только метрики (computed styles), контент и ассеты не копировались. Скрипт — `analyze.js`.

| Параметр | Desktop 1440 | Mobile (iPhone 13) | Как применено в Mona Vita |
|---|---|---|---|
| Текст по умолчанию | 17px, #1d1d1f на #fff | то же | `--fs-body: 17px`, `--ink: #1d1d1f` |
| Заголовок плитки | 40/44px, 600 | 32/36px, 600 | `clamp(32px, 4vw, 48px)` |
| Подзаголовок | 28/32px, 400 | 21–24px | `clamp(19px, 2.2vw, 28px)` |
| Мелкий текст / метки | 12px, #6e6e73 | 12px | `--muted: #6e6e73` |
| Фоны секций | #000 (13), #f5f5f7 (7), #fff | то же | чередование `--bg`, `--bg-alt`, `--bg-dark` |
| Навигация | 44px, rgba(245,245,247,.8), `saturate(1.8) blur(20px)` | 48px | стеклянная nav 52px во всю ширину |
| Кнопки | pill, радиус 980px, 17px, padding 11×21 | то же | pill-кнопки, фирменный розовый #d63a6e (контраст ≥ 4.5:1) |
| Переходы | 0.32s `cubic-bezier(.4,0,.6,1)` (234 эл.), 0.24s ease | — | `--ease: cubic-bezier(.4,0,.6,1)`, 0.32s для hover |

| Видео | 2 автоплей-ролика в плитках | — | живой 3D-адресник (Three.js), «приближается» при прокрутке |
| Скругления | 980px (кнопки), 5–8px мелкие | — | карточки 24px, кнопки pill |

Главные принципы UX:
1. Одна мысль на экран: крупный заголовок, одна строка подзаголовка, две ссылки-CTA («Подробнее» / действие).
2. Плиточная сетка равнозначных промо-блоков с чередованием светлых и тёмных фонов.
3. Минимум декора: типографика, воздух, единый акцентный цвет только для действий.
4. Движение мягкое и короткое; на скролле — только `opacity`/`transform`.
